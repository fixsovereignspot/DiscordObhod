>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские утилиты, после чего удаляет их и отправляет в карантин. В таком случае детект обычно называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, Kaspersky содержит параметр «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы уверенно понимаете настройки исключений, лучше задать исключение. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️ Установка и использование

1. Сначала включите безопасный DNS (Secure DNS).
   * В Chrome включите «Использовать безопасный DNS» и выберите DNS-провайдера, отличного от «Поставщик по умолчанию».
   * В Firefox откройте «DNS через HTTPS», установите режим «Персональный», выберите «Выбрать провайдера/поставщика» и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS непосредственно в настройках ОС. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется.
   * Пользователям роутеров Keenetic нужно включить в настройках параметр «Транзит запросов». При отключённой опции Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/fixsovereignspot/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и включите пункт «Разблокировать». Для архивов, открытых через 7-Zip или PeaZip, это действие можно не выполнять.

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите подходящий файл:
   * Чтобы найти рабочую стратегию, откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
   * Для запуска стратегии вместе с системой выберите **`service.bat`** → `Install Service` → нужная стратегия.

## ℹ️ Для чего нужны файлы

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии `ALT`, `FAKE` и другие, пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск Windows (`services.msc`).</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** — включить или выключить обход для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Значение в скобках показывает, включена ли функция.
  - **`IPSet Filter`** — изменить обработку сервисов из `ipset-all.txt`.  
  Это полезно при проверке ресурса, который без zapret работает, а с ним — нет.  
  Текущее состояние отображается в скобках:
    - `none` — ни один IP не проверяется;
    - `loaded` — IP сверяется со списком;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений.
  - **`Replace active fakes`** — заменить используемый fake на другой из каталога `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — проверить распространённые причины неработоспособности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент.
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — проверить сайты из `utils/targets.txt`;
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, заметный на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/fixsovereignspot/zapret-discord-youtube/issues/522).

### Не нашлась рабочая стратегия

1. Откройте командную строку с правами администратора.
2. Выполните команды по очереди:

   `netsh winsock reset`
  
   `netsh int ip reset all`
  
   `netsh winhttp reset proxy`
  
   `ipconfig /flushdns`

3. Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** запустите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
- скопируйте весь текст из открывшегося блокнота;
- откройте файл `hosts` в созданной папке текстовым редактором, запущенным от имени администратора;
- вставьте скопированный текст в конец `hosts` или замените ранее добавленный аналогичный блок;
- сохраните файл и проверьте подключение. Если результата нет, убедитесь, что сохранение действительно прошло.

#### Работа этого способа не гарантируется. При отсутствии результата используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/fixsovereignspot/tg-ws-proxy) либо любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> После обнаружения определённая стратегия может проработать некоторое время, а затем перестать обходить блокировку.
> Здесь доступно много стратегий. Если ни одна не подходит, создайте новую на основе существующей, изменив её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте ошибки через `service.bat` → `Run Diagnostics`.
- Убедитесь, что нужный адрес присутствует в списке доменов или IP-адресов.
- Попробуйте другие варианты, в том числе **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/fixsovereignspot/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект

- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Откройте `service.bat` → `Remove Services`.
- Выполните `service.bat` → `Run Diagnostics`; исправьте найденные ошибки и в конце ответьте `Y`.
- Удалите старую папку zapret.
- Скачайте новую версию со [страницы релизов](https://github.com/fixsovereignspot/zapret-discord-youtube/releases) — архив `zapret-discord-youtube-...`.
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть «Разблокировать», установите флажок, нажмите «Применить» и «ОК».
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов.
- Запускайте разные `general`-скрипты и проверяйте доступ к интернет-ресурсам. Если выбранный вариант не работает, закройте программу через значок замка на панели задач и перейдите к следующей стратегии.
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` → `Install Service` → нужная стратегия.

### Игра или приложение не работает при включённом zapret

Убедитесь, что в `service.bat` параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на неожиданные для вас ресурсы.

### Античит сообщает о проблеме с WinDivert

Инструкция доступна здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Узнайте имя службы в командной строке Windows (`Win+R`, затем `cmd`):

```cmd
driverquery | find "Divert"
```

2. Подставьте полученное имя в следующие команды, чтобы остановить и удалить службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что включён [Secure DNS](#%EF%B8%8F-установка-и-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше доступ был, а затем исчез.
- Смотрите также [#251](https://github.com/fixsovereignspot/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8F-установка-и-использование).
- Сначала выясните, на какой стратегии открывается YouTube, и запустите её.
- В `service.bat` выберите `Run Diagnostics` и очистите там кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно пользуйтесь ей.
- Если сайт тоже не открывается, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/fixsovereignspot/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/fixsovereignspot/tg-ws-proxy).
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Начните с универсальной последовательности:
- обновите ipset через `service.bat` и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

У режима `ipset any` есть побочный эффект: многие сайты могут перестать открываться. Не оставляйте его включённым постоянно. Вместо этого определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/fixsovereignspot/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

Создайте обращение [здесь](https://github.com/fixsovereignspot/zapret-discord-youtube/issues).

## 🗒️ Как добавить адреса других ресурсов

Дополнительные адреса можно распределить по следующим файлам:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не следует;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети-исключения.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
